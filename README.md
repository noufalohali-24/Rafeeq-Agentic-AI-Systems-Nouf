# Rafeeq Mini Capstone

## Overview

Rafeeq Mini Capstone is a bilingual Agentic AI engineering project developed as part of the SDAIA Academy program:

**Advanced Agentic AI Systems Engineering**

The project simulates a safe and auditable delivery-support agent for a fictional delivery company (Tawseel). The system processes customer requests in Arabic and English, validates ownership, retrieves applicable policies, delegates tasks to specialized agents, applies refund rules, and generates auditable evidence while maintaining security and privacy controls.

---

## Project Objectives

The project demonstrates:

- Agent-based orchestration
- State management
- Memory and retrieval systems
- Policy-aware decision making
- Refund approval workflows
- Secure tool usage
- Redacted tracing and auditing
- Safety guard implementation
- Evaluation and assessment reporting
